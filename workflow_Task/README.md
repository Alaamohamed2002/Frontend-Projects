# Task Flow 📝

A modern and responsive Task Management Web Application built with HTML, CSS, and Vanilla JavaScript.  
Task Flow helps you organize, track, and manage your daily tasks efficiently with a clean dashboard and persistent local storage.

## 🚀 Live Demo
https://alaamohamed2002.github.io/Frontend-Projects/workflow_Task/

## ✨ Features

### **1. Dashboard**
- Quick overview of all tasks
- "Recent Tasks" section with instant add
- Mark tasks as complete or delete them
- Shows "Due in X days" or "Due X days ago" automatically

### **2. Task Management**
- **Add Task**: Title, Description, Priority, Start Date, Due Date
- **Priority System**: High - Medium - Low with color coding on select
- **Filters**: All Tasks, Due Today + Overdue, High/Medium/Low Priority
- Overdue tasks automatically appear in "Due Today" so nothing gets missed

### **3. Statistics Page**
- **Total Tasks**
- **Completed Tasks** 
- **Pending Tasks**
- **Tasks This Week**
- Responsive card design with Font Awesome icons

### **4. Settings**
- Export all tasks as JSON
- Add sample tasks
- Clear all tasks with confirmation modal

### **5. Core Tech Details**
- **Data Persistence**: All data saved in `LocalStorage`. Nothing is lost on refresh.
- **Responsive Design**: Works perfectly on Desktop, Tablet, and Mobile using CSS Grid
- **UI/UX**: Clean design with teal and purple theme. Font Awesome icons used across the app.

## 🛠️ Technologies Used
- **HTML5**
- **CSS3** - Flexbox & Grid
- **JavaScript ES6** - DOM Manipulation, Date Objects, LocalStorage
- **Font Awesome** for icons
